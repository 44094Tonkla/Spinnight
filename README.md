# Spinnight 🍻🍾

A real-time multiplayer party web application powered by React, Vite, and Firebase Cloud Firestore.

## 🎮 Features & Mini-Games

- **🍾 Wheel / Spin Bottle**: Classic random player picking for party challenges.
- **🃏 Card Game**: 52-card deck with rank-based rules & custom rule preset management.
- **🙋 Never Have I Ever**: Real-time prompt creation, 2-choice voting (EVER vs NEVER), and instant reveal results.
- **💣 Bomb Roulette**: Ticking secret bomb timer, real-time passing mechanics, and explosion reveal screen.
- **🔥 Firebase Real-time Integration**: Anonymous auth, Firestore room sync, multi-tab / multi-device multiplayer.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/44094Tonkla/Spinnight.git

# Navigate to directory
cd Spinnight

# Install dependencies
npm install

# Start development server
npm run dev
```
